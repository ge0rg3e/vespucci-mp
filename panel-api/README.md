## Scripts

<ul>
<li>npm start - Starts the app in development mode (aka using Nodemon with Hot Reload)</li>
<li>npm run dev - Starts rollup that will watch and compile all typescript into common js.</li>
<li>npm run serve - Starts the app for production use.</li>
<li>npm run build - Builds the app source code from Typescript to Common JS.</li>
<li>npm run lint - Quick eslint test across all files.</li>
</ul>
